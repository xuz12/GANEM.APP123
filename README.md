# رواد - منصة ولاء المشجعين

منصة متكاملة لإدارة حضور المشجعين ونظام النقاط والمكافآت للدوري السعودي للمحترفين (دوري روشن).

## المميزات الرئيسية

### 🎯 نظام إثبات الحضور المتقدم
يدعم التطبيق ثلاث طرق لإثبات الحضور:

1. **السياج الجغرافي (Geofencing)**
   - تحقق تلقائي من موقع المستخدم
   - دقة عالية مع نطاق قابل للتخصيص لكل ملعب
   - مكافأة للحضور المبكر (+25 نقطة)
   - مكافأة البقاء حتى النهاية (+25 نقطة)

2. **رمز QR**
   - مسح سريع وسهل
   - رموز فريدة لكل مباراة
   - دقة 99%

3. **علامات NFC**
   - تقنية لمس وتشغيل
   - الأكثر أماناً ودقة
   - دعم للأجهزة الحديثة

### 💎 نظام النقاط الديناميكي

#### كسب النقاط:
- **الحضور للمباريات**:
  - مباراة عادية: 100 نقطة
  - مباراة ديربي: 150 نقطة (×1.5)
  - مباراة نهائية: 200 نقطة (×2)
  - دوري أبطال آسيا: 250 نقطة (×2.5)

- **مكافآت الولاء**:
  - 5 مباريات متتالية: +200 نقطة
  - 10 مباريات متتالية: +500 نقطة
  - حضور جميع مباريات الموسم: +2000 نقطة

- **التفاعل اليومي**:
  - تسجيل الدخول اليومي: 5 نقاط
  - مشاركة المحتوى: 10 نقاط
  - التوقعات الصحيحة: 50 نقطة

- **برنامج الإحالة**:
  - دعوة صديق: 100 نقطة
  - أول حضور للصديق: 200 نقطة إضافية

### 🏆 نظام المستويات (5 مستويات)

1. **المشجع الجديد** (0-999 نقطة)
   - خصم 20% على أول استبدال
   - الوصول للعروض الأساسية

2. **المشجع النشط** (1,000-4,999 نقطة)
   - مضاعف نقاط ×1.2
   - عروض إضافية شهرياً
   - شارة رقمية خاصة

3. **المشجع المخلص** (5,000-14,999 نقطة)
   - مضاعف نقاط ×1.5
   - أولوية في الحجوزات
   - خصم 15% دائم

4. **السوبر فان** (15,000-29,999 نقطة)
   - مضاعف نقاط ×2
   - لقاء مع اللاعبين
   - تذكرتين VIP مجانية
   - خصم 25% دائم

5. **الأسطورة** (30,000+ نقطة)
   - مضاعف نقاط ×2.5
   - وصول لكل الفعاليات
   - اسم في قاعة مشاهير المشجعين
   - خصم 35% دائم

### 🎁 نظام المكافآت والاستبدال

- **مطاعم وكافيهات**: ستاربكس، ماكدونالدز، البيك
- **تسوق**: نايكي، أديداس، إكسترا، جرير
- **ترفيه**: سينما VOX، مدن ترفيهية
- **خدمات**: صالونات، غسيل سيارات

كل عرض يحتوي على:
- كود استبدال فريد
- صلاحية 30 يوم
- شروط وأحكام واضحة

## التقنيات المستخدمة

### Frontend
- **React 18** مع TypeScript
- **Vite** للبناء والتطوير السريع
- **Tailwind CSS** للتصميم
- **Lucide React** للأيقونات
- دعم كامل للعربية والـ RTL

### Backend
- **Supabase** (قاعدة بيانات + مصادقة + real-time)
- PostgreSQL مع Row Level Security
- PostGIS لحسابات السياج الجغرافي

### APIs المستخدمة
- Geolocation API للموقع
- Web NFC API لعلامات NFC
- Camera API لمسح QR

## البنية التحتية لقاعدة البيانات

### الجداول الرئيسية:
- `clubs` - معلومات الأندية والملاعب
- `user_profiles` - بيانات المستخدمين والنقاط والمستويات
- `matches` - المباريات وتفاصيلها
- `attendance_records` - سجلات حضور المباريات
- `points_transactions` - جميع معاملات النقاط
- `partners` - الشركاء التجاريين
- `partner_offers` - العروض المتاحة
- `redemptions` - عمليات الاستبدال
- `user_referrals` - الإحالات

### الأمان:
- Row Level Security (RLS) مفعل على جميع الجداول
- سياسات محددة للقراءة والكتابة
- التحقق من الملكية والصلاحيات
- تشفير البيانات الحساسة

### الدوال المساعدة:
- `is_within_geofence()` - التحقق من السياج الجغرافي
- `calculate_user_level()` - حساب مستوى المستخدم
- `generate_referral_code()` - توليد كود إحالة فريد

## التثبيت والإعداد

### المتطلبات:
- Node.js 18+
- npm أو yarn
- حساب Supabase

### خطوات التثبيت:

1. استنساخ المشروع:
\`\`\`bash
git clone [repository-url]
cd rawad
\`\`\`

2. تثبيت الحزم:
\`\`\`bash
npm install
\`\`\`

3. إعداد المتغيرات البيئية:
أنشئ ملف `.env` في الجذر:
\`\`\`env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
\`\`\`

4. إعداد قاعدة البيانات:
   - قاعدة البيانات جاهزة ومُعدّة مسبقاً
   - جميع الجداول والبيانات الأولية موجودة

5. تشغيل التطبيق:
\`\`\`bash
npm run dev
\`\`\`

6. بناء للإنتاج:
\`\`\`bash
npm run build
\`\`\`

## الاستخدام

### للمشجعين:

1. **التسجيل**:
   - أنشئ حساب جديد
   - اختر فريقك المفضل
   - احصل على كود إحالة خاص

2. **حضور المباريات**:
   - افتح التطبيق قبل المباراة
   - اختر طريقة إثبات الحضور
   - اكسب النقاط تلقائياً

3. **استبدال النقاط**:
   - تصفح العروض المتاحة
   - اختر العرض المناسب
   - احصل على كود الاستبدال
   - استخدمه عند الشريك

4. **دعوة الأصدقاء**:
   - شارك كود الإحالة
   - اكسب نقاط إضافية
